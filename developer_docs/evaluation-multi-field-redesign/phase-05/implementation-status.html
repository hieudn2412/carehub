Đối chiếu implementation với ADR random, overlap, snapshot và idempotency.

Contract sinh đề

  • POST /exam-papers/generate bắt buộc idempotencyKey; nhận variantCount, master seed qua randomSeed và zeroOverlap.
  • Cùng key và cùng payload trả lại các paper của batch cũ; payload khác trả HTTP 409.
  • Response paper có batch ID, master seed, variant index, config version, algorithm version, pool checksum, overlap và actual coverage.

Thuật toán

  • Khóa pessimistic config trong transaction; pool lấy trực tiếp từ câu APPROVED, category/field active, cognitive đã xác nhận và source filter theo ID.
  • Pool sort theo ID trước khi shuffle; seed từng mã được hash từ master seed, variant index và DIRECT_BANK_V1.
  • Chọn không hoàn lại theo từng field × cognitive; loại câu cùng root family/paraphrase trong một đề.
  • Zero-overlap kiểm tra số family từng cell trước khi tạo và loại family đã dùng khỏi toàn batch.
  • Pool checksum gồm algorithm version, config version, source filters và ID/family/updatedAt của candidate.

Snapshot và phát hành

  • Batch snapshot từng cell field/cognitive với ID, code, name, label và required count.
  • Mỗi dòng câu snapshot nội dung, vị trí, thứ tự đáp án đã xáo và đáp án đã remap, taxonomy, cognitive, tài liệu, family và metadata generation.
  • Publish đối chiếu actual matrix từ snapshot với batch blueprint; generation chỉ tạo DRAFT và không tự publish.
  • Trang quản trị cho preview lại nguồn, sinh nhiều mã, xem overlap và ma trận snapshot trước khi phát hành.

Nghiệm thu

  • Unit/contract: seed, checksum, request hash, family; direct query; tái lập; idempotency; checksum conflict; family de-dup; zero-overlap; rename taxonomy giữ nguyên snapshot; shuffle option remap đáp án.
  • Integration: hai request đồng thời cùng key tạo đúng một batch và một mã đề; thiếu một cell rollback toàn batch.
  • API system: luồng generate/publish và toàn bộ lifecycle cũ tiếp tục xanh với idempotency bắt buộc.
  • Backend: 842 tests, 0 failure, 0 error, 9 skipped; Maven package thành công.
  • Frontend: 26 test files / 154 tests, lint và production build thành công.
Triển khai DB: remote hiện ở Flyway V13 sau backup và verify read-only; không reset hoặc seed dữ liệu.

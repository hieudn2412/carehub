Backend

  • V10 thêm audience, source scope, blueprint version, pool checksum và filter category/document theo ID.
  • API nhận field blueprint và đúng ba cognitive cell mỗi field; request mới không cần question set hay mục đích kiểm tra.
  • Preview/generation query trực tiếp câu APPROVED, category ACTIVE, field đúng, cognitive đã verified; shortage từng cell chặn activate/generate.
  • Largest remainder lưu cả tỷ lệ và số câu, tie-break theo display order; checksum SHA-256 cảnh báo pool thay đổi.

Frontend

  • Wizard chọn audience, tổng câu, thời lượng, nhiều lĩnh vực và tỷ lệ ba mức: Kiến thức nền tảng, Áp dụng lâm sàng, Tư duy và phân tích lâm sàng.
  • Payload gửi audienceId, fieldBlueprints, sourceFilters; không gửi questionSetId.

  • Acceptance boundary: tổng 1, 2, 3, 7, 10, 20, 101; tie 33/33/34; không fallback sang field/cognitive khác.
